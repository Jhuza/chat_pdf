# ChatPDF

Conversa con un PDF a partir del texto de sus páginas.

- Entrada: PDF con texto seleccionable y una pregunta.
- Resultado: Respuesta basada en fragmentos del documento.
- Tecnología: LangChain · FAISS · GPT-4o mini

## Uso

Carga el PDF, introduce tu clave de OpenAI y escribe una pregunta. Pulsa Consultar documento.

## Límites

Necesita una clave de OpenAI. No realiza OCR y las respuestas deben contrastarse con el PDF.
